# Threads 人物誌｜AI 人物研究實驗 v0.1

在 Threads 看到一個有趣的人，常常只看了幾篇貼文就按下追蹤。這個小實驗是用 AI 幫忙讀原文、整理觀點、找反例，再由自己挑出真正有興趣的問題，寫成自己的分享。

這不是人物排名，也不是已證實有效的學習方法。先研究一個人，看看自己到底學到什麼，再調整流程。

## 開始玩

1. [下載空白研究桌 TEMPLATE.xlsx](./TEMPLATE.xlsx)，在 Google Sheets 選擇「檔案 → 匯入」上傳成新的試算表。原始檔是空白模板，不含本人的研究紀錄。
2. 在 People 加入一位你想研究的人，給他一個 Person ID。
3. 把 [PROMPTS.md](./PROMPTS.md) 的蒐集提示詞和自己的研究桌連結交給能讀公開 Threads 的 AI；不能讀原文就標記，不能寫表就回傳可貼上的資料。
4. 找另一個 AI 補充或反駁；讀 Discussion 後親自選一個你想寫的視角。
5. 先講出自己的想法，再請 AI 做有限度編輯。由本人確認後才發布。

[完整方法](./METHOD.md) ｜ [提示詞](./PROMPTS.md) ｜ [空白研究桌](./TEMPLATE.xlsx)

不必使用指定 AI，不需要 API、排程、資料庫、爬蟲或自行部署。各服務能否讀 Threads、存取 Google Sheets，取決於實際授權和功能；不能存取時可手動複製貼上。

**隱私：**研究桌請先維持私人。只收集必要的公開資料；評分是自己的注意力分配，不是對他人的能力或人格排名。發布時引用可核對的原始來源，不公開私人評分、對話、非公開帳號或研究桌連結。

v0.1 是試行版，歡迎拿去做自己的小實驗。
