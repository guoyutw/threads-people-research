## 人物與研究問題

作者自述經歷失業、創業負債、從零學程式轉職工程師及任教，後來投入 Threads 行銷顧問、代操及培訓。核讀時約2.9萬粉絲。這次研究聚焦三軍策略的早期形成、可複製性及吸引有效受眾的問題。

## 公開觀察

- 2024年4月訪談顯示早期由轉貼與整理逐漸增加原創觀點；同年12月已公開談三軍策略。此前有其他平台寫作、社群及講師經驗，不能把帳號起步等同於能力、人脈從零開始。
- 三軍分別著重曝光、專業追蹤、故事與信任。官網自述分析6,000篇貼文；不同教學文章推薦比例並不相同。原始逐篇數據、轉換定義、對照及受眾留存未取得，不能證明最佳配比或普遍成效。
- 正式文章把對演算法及不精準受眾的疑問連到向內、向外探索的個人目的，而非直接承諾複製策略。
